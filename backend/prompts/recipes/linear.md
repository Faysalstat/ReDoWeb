# linear — Modern Tool / Builder SaaS

**Vibe**: Quiet luxury for developer/software tools; warm dark, hairline detail, restraint as confidence.
**Best for**: software/SaaS, professional/technical services, agencies, any brand whose tone reads "professional", "corporate", "trusted", "enterprise".

## Palette approach
- Ground: near-black with a warm undertone (never pure `#000000`), e.g. `#08090A`.
- Two raised surface levels above ground, separated by hairline borders (`rgba(255,255,255,0.06)`), not shadows.
- Primary brand color appears on under 5% of pixels — focus/active states, small pills, key CTAs — never as a body background.
- Secondary/accent: a very subtle, low-opacity gradient mesh in the hero only (feathered, not the saturated purple-pink AI cliché).

## Typography
- Display: a tight geometric sans at weight 600, tight tracking (-0.02em) -- Space Grotesk fits well.
- Body: Inter at 14-15px, weight 400-500, line-height 1.55.
- Mono for inline code / shortcut chips / small labels -- JetBrains Mono.

## Spacing
4 / 8 / 12 / 16 / 24 / 40 / 64 / 96.

## Radius
6 (small UI) / 12 (cards) / 16 (large panels). Never above 16 — "modest, precise, never gummy."

## Shadow
Barely there: soft `0 1px 2px rgba(0,0,0,0.3)` on raised surfaces only. Never glow, never a colored shadow.

## Motion
Ease-out ~150ms for hover, 350-450ms for layout moves with a quint curve. Snappy, never bouncy or elastic.

## Signature moves
- Hairline 1px borders separating every panel, everywhere.
- Selective, disciplined accent use — never flooding a background.
- Keyboard-shortcut-style chips and monospace inline code.
- A real product/site screenshot anchoring the page, not an abstract illustration.

## Avoid
- Bouncy or elastic easing.
- More than one saturated accent color.
- Radius above 16px.
- Stock photography of people.
