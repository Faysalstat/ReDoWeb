# vercel-mesh — Modern Tool / Builder SaaS (alt.)

**Vibe**: Black-and-white precision broken by one restrained, feathered gradient mesh.
**Best for**: technical/platform products, tools, anything wanting "modern, sleek, premium, tech" without leaning as dark-lounge as `linear`.

## Palette approach
- Ground: true black to near-black.
- Primary text near-white, secondary text mid-gray, hairline borders at low white opacity.
- One full-bleed gradient mesh used ONLY in the hero (or one section break) — diffuse, low-saturation, feathered to black edges. Never more than one mesh on the page.
- CTA buttons: solid, high-contrast (light-on-dark), no gradient, no colored shadow.

## Typography
- Display: a technical/geometric sans, weight 500-600 -- Sora fits well.
- Body: Inter, 15-16px, weight 400, line-height 1.6.
- Mono for code, terminal-style output, or any real system/status readout -- Space Mono.

## Spacing
4 / 8 / 16 / 24 / 40 / 64 / 96 / 128.

## Radius
8 (small) / 12 (medium) / 16 (large) — slightly more generous than `linear`, still disciplined.

## Shadow
Minimal at the component level — the page should feel lit by the mesh, not by drop shadows.

## Motion
Snappy ease-out, ~200ms hovers, 500-700ms layout moves. The mesh itself may drift slowly (10-20s loop) if animated.

## Signature moves
- One feathered gradient mesh, low saturation, dreamy — not the saturated purple-pink AI-default gradient.
- Otherwise strictly black-and-white with hairline detail and monospace accents.
- Real, believable technical/status content as a hero element rather than lorem-ipsum copy.

## Avoid
- Bright saturated purple-to-pink gradients (this recipe exists specifically to replace that cliché).
- More than one mesh per page.
- Glow effects on every component — reserve for one hero moment.
- Colored buttons — the signature button is solid light-on-dark.
